# F1 Telemetry & Race Analytics Platform

Estrutura inicial do projeto.

## Estrutura

- `src/` - código-fonte da aplicação
- `tests/` - testes automatizados
- `notebooks/` - notebooks de análise e exploração
- `configs/` - arquivos de configuração
- `scripts/` - scripts utilitários e automações
- `docker/` - configurações do Docker
- `docs/` - documentação do projeto
- `.github/` - workflows e configurações do GitHub

## Como começar

1. Crie o ambiente virtual
2. Instale as dependências
3. Configure o projeto em `pyproject.toml`
4. Inicie a aplicação ou os notebooks
